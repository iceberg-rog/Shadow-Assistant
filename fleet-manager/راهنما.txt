====================================================================
  Fleet Manager  —  راهنمای فارسی
====================================================================

فایل اجرایی:  dist\FleetManager.exe
روی هر ویندوزی کپی کن و دوبار کلیک کن. یک صفحه توی مرورگر باز می‌شود.
(هیچ چیزی روی اینترنت باز نمی‌شود؛ فقط روی همان کامپیوتر است.)

کنار فایل exe این‌ها ساخته می‌شوند — مواظبشان باش:
  fleet.db        = دیتابیس (سرورها، کاربرها، مصرف، تاریخچه)  ← بکاپ بگیر!
  fleet_key(.pub) = کلید SSH خودِ برنامه

--------------------------------------------------------------------
۱) اضافه کردن سرور  (تبِ Servers)
--------------------------------------------------------------------
IP + یوزر + رمز را بده و «Check & add» بزن.
برنامه خودش وصل می‌شود و تشخیص می‌دهد که سرور «ایران» است یا «خارج»
(و می‌نویسد چرا: geo says IR / geo says US).
اگر اشتباه تشخیص داد، با دکمه‌ی ⇄ کنارِ نقش، دستی عوضش کن.

اگر سرور رمز قبول نمی‌کند (فقط کلید SSH):
  توی همان صفحه یک خط دستور هست → Copy کن → روی سرور اجرا کن →
  بعد در «Login» گزینه‌ی «Fleet key» را انتخاب کن. دیگر رمز نمی‌خواهد.

--------------------------------------------------------------------
۲) ساخت سرویس جدید  (تبِ New service)
--------------------------------------------------------------------
سرور ایران + سرور خارج را انتخاب کن و «Install everything» بزن.
برنامه خودش:
  - روی سرور خارج تونل را نصب می‌کند
  - روی سرور ایران OpenVPN + L2TP + پنل کاربران را نصب می‌کند
  - این دو را به هم وصل می‌کند
  - در آخر ۶ تستِ کامل می‌گیرد و نتیجه را نشان می‌دهد:
      تونل / خروج از سرور خارج / OpenVPN / پنل / حساب‌داری / DNS
در پایان آدرس پنل + یوزر و رمز پنل + PSK را می‌دهد.

اگر سرویس از قبل ساخته شده و می‌خواهی وارد برنامه شود:
  همان تب، پایین‌تر: «Already have a running pair?» → Import it
  کاربرها با مصرف و روزهایشان وارد دیتابیس می‌شوند (چیزی نصب نمی‌شود).

--------------------------------------------------------------------
۳) کاربرها  (تبِ Users)
--------------------------------------------------------------------
برای هر کاربر مشخص می‌کنی:
  Days   = چند روز اعتبار (۰ = بی‌نهایت)
  GB     = چند گیگ حجم    (۰ = بی‌نهایت)
  Devices= چند دستگاه همزمان (۰ = بی‌نهایت)
هرچه اینجا بزنی همان لحظه روی سرور اعمال می‌شود.
اگر کاربری بیشتر از سقفِ دستگاهش وصل شود، اتصال‌های اضافه قطع می‌شوند.

کاربرها با فایل .ovpn (از پنل سرور) + یوزر/رمز خودشان وصل می‌شوند.

--------------------------------------------------------------------
۴) تعویض سرور  (تبِ Replace a server)  ★ مهم ★
--------------------------------------------------------------------
الف) «Replace the FOREIGN server» — وقتی سرور خارج فیلتر شد:
     سرویس + سرور خارجِ جدید را انتخاب کن → Swap the exit
     ← کاربرها هیچ تغییری حس نمی‌کنند (آدرس ایران همان است)
     ← حجم مصرفی و روزهای باقی‌مانده دست‌نخورده می‌ماند

ب) «Replace the IRAN server» — وقتی سرور ایران را عوض می‌کنی:
     سرویس + سرور ایرانِ جدید را انتخاب کن → Rebuild
     ← همه‌چیز از نو نصب می‌شود و همه‌ی کاربرها با
       «حجم مصرف‌شده» و «روزهای باقی‌مانده» برمی‌گردند
     ← فقط باید آدرس جدید ایران را به کاربرها بدهی

نکته: چون همه‌چیز داخل fleet.db است، حتی اگر سرور قبلی
کاملاً مرده باشد، کاربرها از روی دیتابیس برمی‌گردند.

--------------------------------------------------------------------
۵) داشبورد  (تبِ Dashboard)
--------------------------------------------------------------------
تعداد سرورها / سرویس‌ها / کاربرها، مجموع ترافیک، تعداد آنلاین،
نمودار مصرف در طول زمان (با تاریخ و ساعت)، و آخرین رویدادها.
دکمه‌ی refresh روی هر سرویس، مصرف لحظه‌ای را از سرور می‌خواند.
برنامه هر ۵ دقیقه هم خودکار به‌روزرسانی می‌کند (اگر باز باشد).
